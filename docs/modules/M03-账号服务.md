## 内部数据结构

```typescript
// User — 用户记录
interface User {
  id: string;          // UUID
  username: string;    // 用户名
  passwordHash: string; // salt:hash 格式
  createdAt: number;   // Unix 时间戳
}

// UserSession — 登录会话
interface UserSession {
  userId: string;      // 用户ID
  token: string;       // 会话令牌 UUID
  expiresAt: number;   // 过期时间（7天后）
}
```

## 函数实现清单

| 函数名 | 签名 | 职责 | 预估行数 |
|--------|------|------|:---:|
| hashPassword | (password: string) => string | PBKDF2 + 随机盐 → "salt:hash" | 8 |
| verifyPassword | (password, stored) => boolean | 提取盐 → 重新哈希 → 比对 | 8 |
| register | (username, password) => User | 检查重复 → 哈希密码 → INSERT | 15 |
| login | (username, password) => UserSession | 查用户 → 验证密码 → 创建session | 20 |
| validateSession | (token) => string | null | 查session → 检查过期 → 返回userId | 10 |
| registerIpcHandlers | () => void | 注册4个IPC通道处理器 | 25 |

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 用户名重复 | 抛 Error("用户名已存在") |
| 用户名不存在 | 抛 Error("用户名不存在") |
| 密码错误 | 抛 Error("密码错误") |
| 用户名/密码为空字符串 | 抛 Error("用户名不能为空") / Error("密码不能为空") |
| Session 过期 | validateSession 返回 null |
| 数据库写入失败 | better-sqlite3 原生异常，向上抛 |
