## 对外接口

```typescript
// 运行结果
export interface RunResult {
  success: boolean;
  output: string;        // 程序输出（stdout）
  error?: string;        // 错误信息（编译错误或运行时错误）
  executionTimeMs: number;
}

export async function runCode(code: string): Promise<RunResult>;
//  编译并执行 TypeScript 代码
//  @param code 用户编写的 TS 代码字符串
//  @returns 执行结果（含输出和耗时）
//  @throws 不抛异常，所有错误封装在 RunResult.error 中

export function verifyOutput(actual: string, expected: string): boolean;
//  比对实际输出和预期输出（trim 后精确匹配）

export function validateCode(code: string): string | null;
//  代码安全校验
//  @returns null 表示通过，否则返回错误描述
//  检查：长度限制、禁止 import/require、禁止 fs/child_process/process.exit

export function registerIpcHandlers(): void;
//  注册 IPC: code:run
```

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 代码过长 | validateCode 返回错误描述 |
| 代码含禁用操作 | validateCode 返回错误描述 |
| TypeScript 编译错误 | esbuild.transform 抛异常 → 捕获在 runCode |
| 运行时错误 | execSync 抛异常 → 捕获在 runCode |
| 执行超时（>5秒） | execSync timeout 抛异常 → 返回 error |
| 无限循环 | Node 进程超时杀 → 返回 timeout 错误 |
| 临时文件清理失败 | finally 中 try/catch 吞异常 |
