### Props & State
```typescript
// 路由参数
// /learn/:chapterId/:sectionId

// 组件内部 State
const [code, setCode] = useState('');          // 编辑器代码
const [result, setResult] = useState<RunResult | null>(null);
const [isRunning, setIsRunning] = useState(false);
const [section, setSection] = useState<Section | null>(null);
const [completed, setCompleted] = useState(false);
```

### 数据流
```
1. 进入页面 → 根据路由参数加载 Section 数据
2. section.starterCode → 设置编辑器初始代码
3. section.content → 渲染概念卡片 (Markdown)
4. 用户修改代码 → setCode()
5. 用户点运行 → snailAPI.runner.run(code) → setResult()
6. Console 组件比对 result.output vs section.expectedOutput
7. 通过 → 标记完成 → snailAPI.progress.completeSection()
8. 下一节按钮亮起
```

### 核心逻辑伪代码
```typescript
// LearnPage 组件:
//   useEffect on [chapterId, sectionId]:
//     1. 加载 section 数据（从课程数据模块）
//     2. 如果 section 有 starterCode → setCode(starterCode)
//     3. 查询进度：isSectionCompleted(userId, sectionId) → setCompleted()
//     4. 如果有保存的用户代码 → 加载并设置编辑器

//   handleRun():
//     1. setIsRunning(true)
//     2. result = await snailAPI.runner.run(code)
//     3. setResult(result)
//     4. 如果 result.success && expectedOutput.trim() === result.output.trim():
//          setCompleted(true)
//          await snailAPI.progress.completeSection(sectionId)
//     5. setIsRunning(false)

//   handleNext():
//     1. 获取下一节的 sectionId
//     2. navigate('/learn/' + chapterId + '/' + nextSectionId)
```

### 错误处理
| 错误场景 | 处理方式 |
|---------|---------|
| section 数据加载失败 | 显示 "课程数据加载失败" + 返回按钮 |
| Monaco 加载失败 | 降级为普通 textarea |
| 代码执行报错 | Console 显示红色错误信息 |
| 进度保存失败 | console.error + 不阻塞用户操作 |

```typescript
}
```

### 实现要点
```typescript
// 初始化:
//   1. useRef 持有编辑器容器 div
//   2. useEffect 中 monaco.editor.create(container, options)
//   3. options: { theme:'vs-dark', fontSize:13, minimap:{enabled:false}, 
//                 lineNumbers:'on', scrollBeyondLastLine:false, automaticLayout:true }
//   4. 监听 onDidChangeModelContent → onChange(newValue)
//   5. 只创建一次（useEffect []），cleanup 时 dispose()

// 外部 value 变化:
//   useEffect(() => {
//     if (editor && editor.getValue() !== value) {
//       editor.setValue(value);
//     }
//   }, [value]);
```

### 错误处理
| 错误场景 | 处理方式 |
|---------|---------|
| Monaco 加载失败（CDN/资源问题） | try/catch 包裹 create()，失败回退 textarea |
| 超大代码（>100KB） | Monaco 原生限制，不做额外处理 |
| 编辑器销毁后 setValue | ref 判空 |
