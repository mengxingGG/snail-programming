## 对外接口

```typescript
interface Question {
  id: string;
  chapterId: string;
  type: 'choice' | 'fill' | 'code';
  text: string;           // 题目描述
  options?: string[];      // 选择题选项
  answer: string;          // 标准答案
  starterCode?: string;    // 编程题初始代码
  expectedOutput?: string; // 编程题预期输出
}

interface ExamResult {
  score: number;      // 0-100
  passed: boolean;    // ≥70 为通过
  correct: number;    // 答对题数
  total: number;      // 总题数
}

export function getQuestions(chapterId: string): Question[];
//  获取某章的考题列表
//  考题数据嵌入在课程模块中（初期硬编码，后续可配置化）

export function submitAnswers(userId: string, chapterId: string, answers: Record<string, string>): ExamResult;
//  提交答案并评分
//  @param answers { questionId: userAnswer }
//  @returns 评分结果

export function getExamHistory(userId: string): ExamRecord[];
//  获取用户考试历史

export function registerIpcHandlers(): void;
```

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| chapterId 无考题 | getQuestions 返回空数组 |
| 用户未答某题 | 空字符串作为答案，判错 |
| 考试记录写入失败 | 抛异常但不影响评分结果返回 |
| 编程题执行超时 | 视为答案错误 |
| 所有题都答错 | score=0, passed=false |
