## 数据类型定义

```typescript
// 来自 shared/types/course.ts — 已有，此处为完整版

export interface Section {
  id: string;              // "1.1", "3.4" 等
  chapterId: string;       // "ch1", "ch3" 等
  title: string;           // "if — 如果条件成立..."
  content: string;         // Markdown 概念卡片（1-2屏，700字以内）
  starterCode: string;     // 初始代码模板
  expectedOutput: string;  // 预期输出（trim 后比对）
  hint?: string;           // 可选的提示文字
}

export interface Chapter {
  id: string;              // "ch1", "ch2" 等
  title: string;           // "你好，编程世界"
  description: string;     // 一句话描述
  sections: Section[];     // 该章所有节
}

export interface Question {
  id: string;
  chapterId: string;
  type: 'choice' | 'fill' | 'code';
  text: string;            // 题目描述
  options?: string[];      // 选择题选项（4个）
  answer: string;          // 标准答案
  starterCode?: string;    // 编程题初始代码
  expectedOutput?: string; // 编程题预期输出
}

// 总导出
export interface CourseData {
  chapters: Chapter[];
  questions: Record<string, Question[]>;  // chapterId → 考题列表
  totalSections: number;
}
```

## 内容编写规范

### 每节的数据格式

```typescript
// 示例：Ch3.1 — if 条件判断
{
  id: "3.1",
  chapterId: "ch3",
  title: "if — 让程序做选择",
  content: `## 条件判断：if 语句

程序不一定要从头执行到尾。有时候，我们需要根据不同的情况，执行不同的代码。

比如：**"如果年龄大于等于 18，就显示'成年'"**

在 TypeScript 中，用 \`if\` 来实现：

\`\`\`typescript
if (条件) {
  // 条件成立时执行这里
}
\`\`\`

### 关键点
- \`if\` 后面跟一对圆括号 \`( )\`，里面是条件
- 条件的结果必须是布尔值（true 或 false）
- 花括号 \`{ }\` 包裹条件成立时要执行的代码
- **缩进不是必须的，但强烈建议**（让你的代码好看）`,
  starterCode: `let age = 18
if (age >= 18) {
  console.log("成年")
}`,
  expectedOutput: "成年",
  hint: "把 age 的值改成 15 试试，看看输出什么？"
}
```

### 编写规则

| 规则 | 说明 |
|------|------|
| **每节一个概念** | 不要一节讲多个概念 |
| content ≤ 700字 | 1-2 屏，不翻页最好 |
| starterCode 3-10行 | 用户只需小改或填空 |
| expectedOutput 精确 | trim 后与输出完全一致 |
| 示例要可运行 | 用户点运行就能看到结果 |
| 概念卡片用 Markdown | 支持标题、代码块、列表、粗体 |
| 语言通俗 | 像朋友在教你，不是文档 |
