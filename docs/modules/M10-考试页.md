# M10 - 考试页

## 基本信息
- **职责**：考试界面，从 M06 加载考题，按题型分发渲染，提交答案并显示评分结果
- **依赖**：M06 考试验证服务（通过 snailAPI.exam 调用）
- **被依赖方**：无（终端页面）
- **预估代码量**：150 行

## 文件清单

| 文件路径 | 用途 |
|---------|------|
| src/renderer/pages/ExamPage.tsx | 考试主页面：加载考题 + 分发渲染 + 提交评分 |
| src/renderer/components/exam/ChoiceQuestion.tsx | 选择题组件（radio 列表） |
| src/renderer/components/exam/FillQuestion.tsx | 填空题组件（input 输入框） |
| src/renderer/components/exam/CodeQuestion.tsx | 编程题组件（Monaco 编辑器） |

## 组件 Props

```typescript
// ChoiceQuestion
interface ChoiceQuestionProps {
  question: { id: string; text: string; options: string[] };
  selected: string;
  onChange: (value: string) => void;
}

// FillQuestion
interface FillQuestionProps {
  question: { id: string; text: string };
  value: string;
  onChange: (value: string) => void;
}

// CodeQuestion
interface CodeQuestionProps {
  question: { id: string; text: string; starterCode: string };
  value: string;
  onChange: (code: string) => void;
}
```

## ExamPage 数据流

```
1. 进入 /exam/:chapterId
2. 加载考题: snailAPI.exam.getQuestions(chapterId)
3. 按 type 分发:
   - 'choice' → ChoiceQuestion (radio)
   - 'fill'   → FillQuestion (input)
   - 'code'   → CodeQuestion (Monaco)
4. 用户作答 → setAnswers({ questionId: answer })
5. 提交 → snailAPI.exam.submit({ answers, chapterId })
6. 显示评分结果: score, passed(≥70)
```
