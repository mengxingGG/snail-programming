# M08 - 侧边栏导航

## 基本信息
- **职责**：左侧 260px 侧边栏，展示课程章节树，高亮当前节，显示完成状态图标（⏳🔨✅），支持折叠展开
- **依赖**：M07 主题系统（theme.colors/spacing）
- **被依赖方**：M09 学习工作台（LearnPage 中使用）
- **预估代码量**：200 行

## 文件清单

| 文件路径 | 用途 |
|---------|------|
| src/renderer/components/layout/Sidebar.tsx | 侧边栏主组件 + ChapterItem 子组件 |

## 组件 Props

```typescript
interface SidebarProps {
  chapters: Chapter[];           // 全部章节数据
  progress: CourseProgress | null; // 用户进度（已完成节列表）
  onSelectSection: (chapterId: string, sectionId: string) => void;
}
// Chapter 类型来自 shared/types/course.ts
```

## 内部数据结构

```typescript
// 节完成状态枚举
type SectionStatus = 'pending' | 'completed' | 'current';

// 章节导航节点
interface ChapterNode {
  chapter: Chapter;
  isExpanded: boolean;
  sections: SectionNode[];
}

interface SectionNode {
  section: Section;
  status: SectionStatus;   // pending | completed | current
}
```

## 关键逻辑伪代码

```typescript
// Sidebar 组件:
//   1. 从 chapters prop 遍历章节
//   2. 每章渲染 ChapterItem
//   3. 传入: chapter, progress, isExpanded, onToggle, activeSectionId

// ChapterItem 组件:
//   1. 渲染章标题行（左侧折叠箭头 ▶/▼ + 章名）
//   2. 点击标题 → toggle 折叠
//   3. 折叠时隐藏 SectionItem 列表
//   4. 展开时渲染所有 SectionItem

// SectionItem 组件:
//   1. 判断状态: section.id === activeSectionId ? 'current' 
//                : completedSections.includes(section.id) ? 'completed' : 'pending'
//   2. 状态图标: current → ●(accent色) | completed → ✓(success色) | pending → 无
//   3. 当前节高亮背景: bgCard
//   4. 点击 → onSelectSection(chapterId, sectionId)
//   5. hover 时背景微亮
```

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| chapters 为空数组 | 显示 "暂无课程数据" |
| progress 为 null | 所有节显示为 pending |
| sectionId 不存在 | 静默忽略，不崩溃 |
