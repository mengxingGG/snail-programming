## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 数据库文件路径无权限 | 捕获异常，抛 Error("无法创建数据库文件") |
| 建表 SQL 语法错误 | 开发期应暴露，不吞异常 |
| 磁盘空间不足 | better-sqlite3 原生异常，向上抛出 |
| getDb 在 initDatabase 前调用 | 抛 Error("Database not initialized") |

## 边界条件
- [x] 多次调用 initDatabase 幂等（IF NOT EXISTS）
- [x] WAL 模式确保多连接安全
- [x] 数据库文件存在时复用，不存在时新建
