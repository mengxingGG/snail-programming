## 内部数据结构

```typescript
// 来自 shared/types/course.ts
interface CourseProgress {
  userId: string;
  completedSections: string[];   // 已完成的节ID列表
  completedChapters: string[];   // 已完成的章ID列表（所有节都完成才算）
  currentSectionId: string;      // 最后学习的节ID
}

interface CodeFile {
  userId: string;
  filename: string;
  content: string;
  updatedAt: number;
}
```

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| userId 为空 | 抛 Error("userId不能为空") |
| 用户无任何进度 | loadProgress 返回空数组，不报错 |
| 文件不存在 | loadCodeFile 返回 null |
| 文件内容超过 1MB | 抛 Error("文件过大") |

## 边界条件
- [x] 新用户无进度 → loadProgress 返回空 CourseProgress
- [x] 重复标记同一节 → INSERT OR IGNORE 幂等
- [x] 代码文件覆盖保存 → INSERT OR REPLACE
- [x] 进度删除（不暴露给用户，仅内部使用）
