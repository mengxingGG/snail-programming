## 📈 学习路线建议

```
🟢 入门: TS选2个 + Python选2个 → 每个1-3天
🟡 进阶: TS选1个 + Python选1个 → 每个1-2周（完整复刻）
🔴 高手: TS选1个 + Python选1个 → 每个2-4周（源码研读+改造）
```

> 💡 建议：跨语言对比学习效果最好。用 TS 做一个 Todo，再用 Python 做一个 Todo，你会深刻理解语言设计的差异。
