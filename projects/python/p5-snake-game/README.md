# p5-snake-game — 贪吃蛇游戏

## 功能列表
- 使用方向键控制蛇的移动
- 随机生成食物，吃食物后蛇身增长
- 得分显示
- 游戏结束判定（撞墙或撞到自己）
- 重新开始功能

## 学习目标
- Pygame 游戏循环与事件处理
- 面向对象设计（Snake、Food 类）
- 碰撞检测
- 游戏状态管理（枚举）

## 依赖
```bash
pip install pygame
```

## 控制键
| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 移动方向 |
| R | 重新开始 |
| ESC / Q | 退出游戏 |

## 项目结构
```
p5-snake-game/
├── README.md   ← 你在这里
└── snake.py    ← 游戏主程序
```

## 如何运行
```bash
python snake.py
```
